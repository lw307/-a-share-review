# A股复盘与模拟交易 v12

版本：`20261021-live-pwa-v12`

## v12 重点
- 支持 iPhone 主屏幕网页应用图标（Manifest + Apple Touch Icon），可像应用一样打开。
- 页面打开期间每 5 分钟请求刷新，行情/报告/模拟账户每分钟更新显示；手动刷新会等待后台数据任务结束（最多等待 120 秒）。
- 模拟持仓若暂时没有行情，账户市值暂按成本估算并明确标记，不再把该持仓市值直接按 0 计入总资产。
- 行业板块优先尝试东方财富行业实时快照，再回退同花顺实时汇总；不把板块名称清单当行情排名。

## v11 继承功能
- 将市场概览、板块强弱排名、主板观察名单、风险/仓位计算器、模拟账户和复盘报告整合到一个移动端网页。
- 使用 v10 已验证的数据链路：东方财富优先，新浪行情备用；按实际返回值展示，数据不可用时不编造。
- 板块排名展示强度评分、当日涨幅、评分覆盖率和缺失项。
- 观察名单仅允许沪深主板代码：沪市 600/601/603/605，深市 000/001/002/003。
- 风险计算器根据入场价、止损价和风险预算计算理论股数，并受 100 股整数倍、单股约 1 万元上限、可用现金限制。
- 模拟交易仅在本地 SQLite 账户记录，不连接券商、不发送真实委托。初始本金 50,000 元，每只股票买入金额限制约 10,000 元。

## 明确未完成
- 每天 17:24 的定时生成、持久化归档及消息推送尚未实现。
- 完整板块成分股映射不足时，不会虚构龙二、龙三。
- 当前没有可靠的历史回测模块，不承诺每笔收益 5%。
- Render 免费服务重启/休眠可能导致 SQLite 本地文件丢失；如需长期保存模拟交易，请配置持久化磁盘并设置 `SIM_DB_PATH` 到持久化目录。

## 部署到 GitHub（iPhone 网页操作）
1. 打开仓库 `https://github.com/lw307/-a-share-review`。
2. 在仓库根目录上传并覆盖 `app.py`、`index.html`、`requirements.txt`、`render.yaml`、`README.md`，并新增 `manifest.json`、`apple-touch-icon.png`。
3. Commit changes，等待 Render 自动部署。
4. 打开 `https://a-share-review.onrender.com/api/health`，确认 `version` 为 `20261021-live-pwa-v12`。
5. 打开首页并等待数据抓取；首次启动/免费实例唤醒可能需要等待。

## API
- `/api/health`
- `/api/market`
- `/api/report`
- `/api/market-diagnostics`
- `/api/sim/account`
- `POST /api/sim/buy`
- `POST /api/sim/sell`

注意：板块强度是当日横截面比较，不等于资金流向精确测量，也不是收益预测。行情可能延迟或缺失。

## iPhone 主屏幕
部署完成后在 iPhone 的 Safari 打开首页，点击“分享”→“添加到主屏幕”→“添加”。从主屏幕图标打开后，页面在前台时会定时更新；iOS 网页应用不会在关闭后持续后台抓取行情。
