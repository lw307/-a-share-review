# A股每日复盘（板块修复 v4）

## 本次修复
- 行业板块：东方财富实时板块快照失败时，新增同花顺 `stock_board_industry_summary_ths` 行业实时汇总作为备用来源。
- 数据校验：板块数据必须同时包含板块名称和有效涨跌幅数值；同花顺行业/概念名称列表、历史概念事件表不会被当作当日涨幅榜。
- 概念板块：新增优先尝试 `stock_board_concept_spot_em` 实时快照，再尝试备用接口；只有返回有效当日涨跌幅时才显示。若数据源不可用，会明确提示概念榜暂不可用，不会用虚构数据补齐。
- 主板约束：模拟买入和 `/api/stocks` 选股查询仅允许沪深主板（沪市600/601/603/605、深市000/001/002/003），排除创业板、科创板和北交所。
- 股票代码标准化：把 `sh600000`、`sz000001` 这类带市场前缀代码统一成六位代码，避免模拟账户输入代码与行情代码不匹配。
- 版本号：`20261021-sectorfix-v4`。

## 文件
- `app.py`：Flask 后端、行情获取、板块修复、模拟账户 API、报告 API。
- `index.html`：手机端页面。
- `requirements.txt`：Python 依赖。
- `render.yaml`：Render 部署配置。

## 重要说明
1. 行情依赖 AKShare 外部数据接口。接口可能限流、超时或调整字段；数据源失败时会单独标注，不会伪造行情。
2. 行业板块兜底使用同花顺行业实时汇总，可能存在数据延迟；盘中排名不等于收盘排名。
3. 涨停/跌停数为根据行情快照和常见涨跌停比例估算，不是交易所官方精确统计。
4. 模拟交易不连接券商、不执行真实委托；报价可能延迟。佣金按模拟规则计算，不保证与实际券商费用相同。
5. Render 免费实例可能休眠或重启。无持久磁盘时 SQLite 数据可能在部署/重启后丢失。
6. 本版本不会自动向微信/手机推送，也不能保证免费实例每天17:24准时运行；可靠定时任务需额外配置外部定时器。
7. 板块领涨股仅作为观察数据，不自动等于龙一/龙二/龙三；不承诺盈利。
