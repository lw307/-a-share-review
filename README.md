# 龙头雷达（A股复盘与模拟交易）

本包基于既有 `app_v19_1.py` 做了一个小版本修复，保留现有页面与 API。

## 本次修改
- 版本标记升级为 `20261024-mainboard-v19.2-normalizefix`。
- 行情字段标准化补齐 `开盘/开盘价`、`最高价`、`最低价`、`成交股数/vol`、`换手/turnover` 等常见别名，减少真实行情源字段名不一致导致的历史 OHLC/成交量/换手率空缺。
- 移除首页响应中重复设置的 `Cache-Control` 语句。
- 增加轻量回归测试，覆盖代码标准化、当前主板筛选规则及行情字段映射。

## 重要边界
- 当前筛选规则仍然是沪深主板（排除创业板、科创板、北交所），没有在此版本中擅自改变市场范围。
- 板块成分映射与龙一/龙二/龙三仍是未解决的关键问题；没有可靠成分股映射时，系统不能把全市场强势股伪装成某个板块的龙头。
- 形态模型目前是观察候选，不是买入信号；若历史日线不足，不应把箱体突破或趋势回调说成已确认。
- `SIM_DB_PATH=/var/data/simulation.db` 只有在部署平台实际挂载持久化磁盘到 `/var/data` 时才可靠；单独设置环境变量不会自动创建持久盘。
- 本包没有包含用户的线上密钥、数据库或历史账户记录。

## 本地运行（需要 Python 环境）

```bash
pip install -r requirements.txt
python app.py
```

然后打开 `http://127.0.0.1:5000`。

## 回归测试

```bash
pip install pytest
pytest -q
```

## API 自检
- `/api/health`：应用版本和健康状态
- `/api/market-diagnostics`：行情源诊断
- `/api/history-status`：历史快照实际覆盖天数
- `/api/test-sectors`：板块接口诊断

## 手机上线说明
iPhone 本身不能直接执行此项目的 Docker 部署命令。需要将本目录上传到可运行 Python 的云端托管环境，并按平台要求配置持久化磁盘；部署文件仅提供启动配置，不代表已经完成云端部署或真实行情验证。
