# A股复盘与模拟交易 v16

版本：`20261021-mainboard-v16`

## v16 本次改进
- 保留 v14 的后台行情获取、备用数据源诊断、市场情绪、主板观察名单和模拟账户。
- 主线归并分数改为组内最高单板块评分，避免相关概念标签数量较多时把均值误读为更强主线。
- 单日快照候选明确标为“情绪强势观察”，无历史K线时不宣称趋势龙头。
- 新增“主线归并观察”，把华为产业链、通信与5G、软件与网络安全、水产与水域、军工与高端装备、核电与能源装备等相关概念分组展示，减少把重叠概念误读成多条独立主线的风险。归并分数为组内可用板块评分均值，不是资金流指标或未来收益预测。
- 常见指数/基准名称不再混入概念板块排名。
- 保留主板代码校验：沪市600/601/603/605，深市000/001/002/003；不将创业板、科创板、北交所股票列为主板领涨候选。
- 缺少板块成分股映射时，不虚构板块龙二、龙三；不以单日数据伪造主线持续性。

## 重要数据边界
- 备用新浪数据源成功不代表已独立核验；盘中快照不等于正式收盘数据。
- 板块上涨广度如果来源没有提供，仍会标记缺失，不用估算值伪装真实数据。
- 模拟交易仅用于研究，不连接券商、不执行真实委托，也不保证收益。
- Render 免费实例休眠或重启可能清空内存缓存；本地 SQLite 是否持久保存取决于部署环境。
- 当前包不会创建每天17:24的自动推送任务。

## 部署步骤
1. 下载并解压此 ZIP。
2. 在 GitHub 仓库中替换同名文件：`app.py`、`index.html`、`README.md`；保留原有 `requirements.txt`、`render.yaml`、`manifest.json` 和 `apple-touch-icon.png`。
3. 提交变更，等待 Render 自动部署完成。
4. 打开 `/api/health`，确认 `version` 为 `20261021-mainboard-v16`。
5. 打开 `/api/report`，确认返回 `theme_strength_ranked` 字段；再打开首页，进入“板块强弱排名”查看“主线归并观察”。

## 建议验证
- `python -m py_compile app.py`
- 部署后检查 `/api/health`、`/api/market-diagnostics`、`/api/report`。
- 如果行情为空或过期，不据此做模拟买入决策。
